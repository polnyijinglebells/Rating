# Цифровой рейтинг

Полностью офлайн-приложение на PySide6 для расчёта показателя конкурентоспособности военнослужащих по критериям приложений 1–3 предоставленных Правил.

## Возможности MVP

- несколько организаций и единый рейтинг с фильтрацией;
- карточки военнослужащих и безопасное архивирование;
- 34 положительных и 6 отрицательных критериев;
- автоматический расчёт с ограничением максимальных баллов;
- роли `admin`, `operator`, `viewer` и журнал действий;
- экспорт сводного рейтинга и карточки военнослужащего в CSV (открывается в Excel);
- резервное копирование SQLite через штатный механизм SQLite;
- загрузка другой базы приложения с поиском совпадений и выбором: оставить, перезаписать или добавить копию;
- сводные CSV-отчёты и персональные PDF-отчёты;
- справочник должностей с визуальным порядком от высшей к нижестоящей;
- выбор должности сотрудника и вакансии только из справочника своей организации;
- подбор кандидатов на вакансии среди сотрудников со следующей должностью ниже в справочнике;
- учёт академического образования и фильтрация кандидатов по этому признаку;
- маска даты рождения `ДД.ММ.ГГГГ` с автоматической расстановкой точек;
- справочники стран, областей и городов с каскадным выбором в карточке;
- общая таблица мест рождения с фильтрами по стране и области, режимом «все» и очисткой фильтра;
- автоматический формат личного номера `БУКВА-ЦИФРЫ`;
- поиск страны, области и города по части названия с выбором первого совпадения клавишей `Tab`;
- встроенный справочник начисления баллов и исходный DOCX с Правилами;
- единая вкладка «Справочники» с категориями должностей, мест рождения, баллов и подразделений;
- подразделения организаций с поисковым выбором в карточке сотрудника;
- автоматическое добавление новых должностей, подразделений и мест рождения из карточки;
- горячие клавиши `F2` (изменение), `F3` (оценка), `F4` (архив) и `F5` (обновление);
- защита импорта базы и резервного копирования повторной авторизацией администра;
- локальная работа без сети и внешнего сервера.

База хранится в `%LOCALAPPDATA%\DigitalRating\digital_rating.sqlite3`. При первом запуске программа предлагает создать администратора. Пароль должен содержать не менее шести символов.

## Запуск из исходников

Требуется Python 3.12 и PySide6:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Проверки:

```powershell
python -m unittest discover -s tests -v
```

## Сборка EXE и установщика

```powershell
python -m pip install -r requirements-build.txt
.\build.ps1
```

PyInstaller создаёт автономный `dist\DigitalRating.exe`. Если установлен Inno Setup 6 и `ISCC.exe` доступен через `PATH`, скрипт также создаёт установщик в `installer_output`.

## Принятые допущения

- повторяющиеся виды стажа суммируются как отдельные критерии;
- для государственного языка количество `1`, `2`, `3` соответствует уровням B2, C1, C2;
- три указанных в документе основания обучения с отличием представлены счётчиком с максимумом 0,75;
- критерии без явно указанного максимума не ограничиваются;
- временные условия «12 месяцев» и «5 лет» сейчас контролирует оператор по документам; даты подтверждений будут отдельным этапом автоматизации.
